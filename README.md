## 표 구성

`부문 | 직무 | 지역 | 하는 일 요약 | 필요 역량·경험 | 근무강도 | 선호 | 경쟁률 | 합격확률`

- 정렬 기준: 객관적 합격확률 = (채용 TO) × (요건 희소성) ÷ (지원자 쏠림)
- 색상 밴드로 4구간(높음·매우높음 / 중상 / 중 / 낮~중·낮음) 구분

## 주의

- 근무강도·선호도·경쟁률·합격확률은 **공개 J/D + 시장 통념 기반 정성 추정**입니다.
- 실제 TO·지원자 수는 비공개이며 회차별로 달라질 수 있습니다.
